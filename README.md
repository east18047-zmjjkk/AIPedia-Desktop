# AIPedia Desktop

AIPedia 是一部面向 AI 工程学习与岗位准备的中文百科。

**[下载 Windows x64 便携版 v0.1.1](https://github.com/east18047-zmjjkk/AIPedia-Desktop/releases/download/v0.1.1/AIPedia-Windows-x64-v0.1.1.zip)**

1. 解压整个 ZIP。
2. 双击 Create-Desktop-Shortcut.cmd，创建 AIPedia 桌面图标。
3. 双击桌面图标打开 AIPedia。关闭启动窗口即可退出。

也可以在解压后的文件夹里双击 Start-AIPedia.cmd 启动。
