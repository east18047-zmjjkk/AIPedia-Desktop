# AIPedia Desktop

AIPedia 是一部面向 AI 工程学习与岗位准备的中文百科。

**[下载 Windows x64 便携版 v0.1.3](https://raw.githubusercontent.com/east18047-zmjjkk/AIPedia-Desktop/fd7cc865f513ab32bf808336e2a7885e2dc90d9d/AIPedia-Windows-x64-v0.1.3.zip)**

升级前请先退出正在运行的旧版，再从新版目录更新桌面快捷方式。

1. 解压整个 ZIP。
2. 双击 `Create-Desktop-Shortcut.cmd`，创建或更新 AIPedia 桌面快捷方式。
3. 双击桌面图标打开 AIPedia。退出时，在 Windows 任务栏通知区域右键点击 AIPedia 图标，选择「退出 AIPedia」。

也可以在解压后的文件夹里双击 `AIPedia.exe` 启动。
